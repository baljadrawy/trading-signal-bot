# المرحلة 7 — حوكمة المخاطر (2026-08-17)

## النطاق

حارس قبول مركزي يعمل قبل تسجيل أي صفقة جديدة. يحسب المخاطر على رأس مال ورقي
قدره 500 USDT، وصفقة ثابتة 50 USDT، منذ `LEARNING_CLEAN_START`. الربح المحقق
وغير المحقق صافي من تكلفة round-trip المقدرة 0.30%.

## الحدود المطبقة

| القيد | الحد | الإجراء |
|---|---:|---|
| التعرض الإجمالي | 80% | رفض الصفقة التي تتجاوزه (8 صفقات كحد فعلي) |
| الرمز الواحد | 10% | صفقة واحدة للرمز |
| الخسارة اليومية | 3% | وقف فتح صفقات جديدة |
| الخسارة الأسبوعية | 5% / 7% / 10% | نصف السعة / الحد الأدنى / وقف |
| drawdown | 5% / 10% / 15% | نصف السعة / ربع السعة / وقف |
| الخسائر المتتالية | 3 / 5 / 7 | نصف السعة / الحد الأدنى / وقف |

القواطع تمنع الدخول الجديد فقط؛ إدارة الصفقات المفتوحة والوقف والأهداف تستمر.
حالة سوق أو سعر مفقود أو قيمة غير منتهية تفشل بصورة مغلقة.

## الفحص الحي عند التنفيذ

- القرار: `loss_streak_halt`.
- الخسائر الصافية المتتالية عند النشر: 8.
- P&L اليومي والأسبوعي مع غير المحقق عند النشر: -1.19%.
- drawdown من القمة عند النشر: 2.80%.
- خمس صفقات كانت مفتوحة؛ التعرض بعد صفقة افتراضية 60%، أي أن سبب الوقف هو سلسلة الخسائر لا التعرض.

## القرار

بوابة المرحلة مكتملة، لكن حالة التشغيل الحالية **HALT للدخول الجديد**. لا رفع
للمخاطرة ولا تداول حقيقي. الاستئناف يحتاج مراجعة سبب سلسلة الخسائر ثم إعادة تشغيل
يدوية واضحة؛ لا يمسح القاطع السجل التاريخي ولا يغلق الصفقات القائمة اعتباطياً.
