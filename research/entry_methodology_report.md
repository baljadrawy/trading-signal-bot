## 6. الاستنتاج النهائي

### المنهجية الأرجح
**Entry = قرب EMA رئيسية (أي فترة على أي TF، ±3%) أو قرب رقم مستدير سيكولوجي (±2%).**

الدليل الإحصائي: 11/12 = **92%** تحقق واحداً منهما. الحالة الوحيدة التي لم تنطبق (STORJUSDT) يغطيها Fib_0.618_1d بـ 1.2%.

**الصورة الكاملة المرجّحة:**
المصدر يرسم EMAs ومستويات سيكولوجية على الرسم البياني، وينتظر أن يصل السعر إلى تلك المناطق. لا يهم إن كان RSI مرتفعاً أو منخفضاً — العامل الحاسم هو الوصول لمستوى سعري رئيسي.

### درجة الثقة: متوسطة (6.5/10)
- إيجابيات: n=12 كلها لمست Entry، تركيبة 92% قوية، قواعد بسيطة
- سلبيات: عتبة EMA ±3% مرنة جداً (مساحة واسعة)، n=12 صغيرة، لا يمكن استبعاد الصدفة بشكل قاطع

### هل المنهجية قابلة للمحاكاة برمجياً؟

**نعم — جزئياً وبتحفظات.**

يمكن إضافة فلتر `entry_near_key_level` بعد رفع التجميد:

```python
# فلتر لتقييم جودة Entry الخارجية (بعد التجميد فقط)
def entry_near_key_level(price, df_1h, df_4h, df_1d):
    for df in [df_1h, df_4h, df_1d]:
        for period in [20, 50, 100, 200]:
            ema = compute_ema(df['close'], period)[-1]
            if abs(price - ema) / ema < 0.03:
                return True, f"near_ema{period}"
    if round_number_distance(price) < 0.02:
        return True, "round_number"
    return False, None
```

**التحفظ الأهم:** هذا البحث يصف كيف يختار المصدر Entry — لا يضمن ربحية استراتيجيته. القالب الثابت (SL=-4%, T1+4%) اختُبر على بيانات هذا البوت ورُفض (E_adj=-0.269%). الاستخدام المقترح: **تقييم/تصفية التوصيات الواردة** لا محاكاة المصدر الكامل.
